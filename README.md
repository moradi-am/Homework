## اجرا
وابستگی‌ها در requirements.txt. پوشه کاری نوت‌بوک باید H1_Lorenz یا H1_Lorenz/notebooks باشد. Run All آزمون‌های جدید را اجرا می‌کند؛ checkpointهای معتبر با هش پروتکل/کد/پارامتر قابل استفاده مجددند.
REBUILD_HOMEWORK=True تمام نمودارهای حل تاریخی اویلر را در پوشه خروجی جداگانه بازسازی می‌کند. این مرحله طولانی‌تر است و به‌صورت پیش‌فرض غیرفعال است؛ تمام نمودارهای قبلی آرشیو شده‌اند.

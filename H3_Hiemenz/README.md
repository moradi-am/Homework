## صورت سؤال

جریان پایا، دوبعدی و تراکم‌ناپذیر روی صفحهٔ تخت $x_2=0$ با جریان
بیرونی $U_e = a x_1$ ($a>0$) و لزجت سینماتیکی $\gamma$ (همان $\nu$).
با متغیرهای بی‌بعد $x^* = x/\sqrt{\gamma/a}$ و
$u^* = u/\sqrt{\gamma a}$ و فرض تشابهی زیر، معادله و شرایط مرزی را
به دست آورید و عددی حل کنید:

$$u_1^* = x_1^* F'(\eta), \qquad u_2^* = -F(\eta), \qquad \eta = x_2^*$$

$$F''' + F F'' - (F')^2 + 1 = 0, \qquad F(0)=F'(0)=0, \qquad F'(\infty)=1$$

## فرض‌ها و نمادها

| نماد | تعریف |
|---|---|
| $a$ | نرخ کرنش جریان بیرونی، $U_e = a x_1$، بُعد $1/T$ |
| $\gamma$ | لزجت سینماتیکی (در یادداشت با $\gamma$ نوشته شده)، بُعد $L^2/T$ |
| $\sqrt{\gamma/a}$ | طول مشخصه |
| $\sqrt{\gamma a}$ | سرعت مشخصه |
| $\eta$ | متغیر تشابهی، $\eta = x_2^*$ |
| $F$ | تابع تشابهی هایمنز |

## فرمول‌بندی و پاسخ تشریحی

پیوستگی: $\partial u_1^*/\partial x_1^* = F'$ و
$\partial u_2^*/\partial x_2^* = -F'$، پس جمع صفر است.
جای‌گذاری در معادلهٔ مومنتم بی‌بعد
$u_1^* \partial u_1^*/\partial x_1^* + u_2^* \partial u_1^*/\partial x_2^*
= x_1^* + \partial^2 u_1^*/\partial {x_2^*}^2$
می‌دهد: $x_1^*(F')^2 - x_1^* F F'' = x_1^* + x_1^* F'''$، یعنی
$F''' + F F'' - (F')^2 + 1 = 0$.
شرح کامل در مقالهٔ PDF (بخش‌های ۳ تا ۵) آمده است.

**هشدار علامت (اصلاح یادداشت دستی):** در یادداشت،
$u_2^* = F$ و $u_1^* = -x_1^* F'$ آمده بود؛ با آن علامت‌ها، معادله
$F''' - F F'' + (F')^2 - 1 = 0$ و شرط $F'(\infty) = -1$ به دست
می‌آید. در این تمرین قرارداد استاندارد هایمنز گرفته شده است.

## پاسخ نهایی و محدودیت‌ها

- سرعت‌ها: $u_1^* = x_1^* F'(\eta)$، $u_2^* = -F(\eta)$.
- معادله: $F''' + F F'' - (F')^2 + 1 = 0$ (فالکنر–اسکن با $\beta=1$).
- شرایط: $F(0)=0$ نفوذناپذیری، $F'(0)=0$ چسبندگی،
  $F'(\infty)=1$ رسیدن به جریان بیرونی.
- تنش برشی دیوار: $\tau_w = \rho\sqrt{\gamma a^3}\,x_1\,F''(0)$.
- محدودیت: حل پایا و لایهٔ مرزی کلاسیک است؛ گذار، سه‌بعدی بودن و
  اثرات تراکم‌پذیری در دامنهٔ آن نیست.

# پروتکل از پیش ثبت‌شده — روش پروجکشن (H2)

- **قرارداد علامت (نگارش دکتر، صفحهٔ اول):** گام تصحیح
  `u^{n+1} = û^{n+1} + Δt ∇π` و معادلهٔ پواسون
  `∇²π = −∇·û^{n+1} / Δt`، با `π = −p^{n+1}` برای `ρ = 1`.
  جفت علامت دیگر (`−Δt ∇p` با `∇²p = +∇·û/Δt`) معادل است؛
  ترکیب دو جفت با هم مردود است (واگرایی نهایی دو برابر می‌شود).
- **آزمون A (پروجکشن خالص):** میدان میانی برابر میدان دقیق تیلور–گرین
  به‌علاوهٔ گرادیان `φ = 0.3 sin x sin y`؛ پس از یک گام پروجکشن باید
  میدان دقیق بازیابی شود و `max |∇·u| < 1e-10`.
- **آزمون B (تیلور–گرین زمانی):** شبکهٔ تناوبی `64×64`،
  `L = 2π`، `ν = 0.1`، `Δt = 0.005`، تا `t = 1` (۲۰۰ گام).
  معیار: `max |∇·u^{n+1}| < 1e-10` در همهٔ گام‌ها؛ انرژی جنبشی
  با حل دقیق `E(t) = 0.25 exp(−4νt)` مقایسه می‌شود.
- **محدودهٔ اعتبار کد:** دامنهٔ تناوبی و مشتق‌های طیفی است؛
  شرایط مرزی دیواره (بخش ۶ مقاله) در این کد آزمون نشده و فقط
  به‌صورت نظری بیان شده است.
